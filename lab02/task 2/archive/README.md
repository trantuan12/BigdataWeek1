# Bằng chứng lịch sử

Các artifact trong thư mục này và các run cũ được giữ để đối chiếu số liệu trước khi Task 2 được tách thành một thư mục độc lập. Một số frozen code hoặc run records còn ghi đường dẫn của bố cục cũ; đó là nội dung lịch sử, không được driver hiện tại sử dụng.

`previous-input/` lưu bản input và envelopes tương ứng run Quality `e41af4ab-899d-48ae-af76-67d97ba591bc`, phục vụ truy vết các metric cũ. Input hiện hành nằm ở `../input/`; mỗi run hiện hành giữ snapshot và envelopes riêng trong chính thư mục kết quả.

Để chạy và đọc kết quả mới, dùng `../code/run_tasks.py` và `../latest-run.json`. Mã nguồn hiện hành không phụ thuộc đường dẫn ngoài thư mục Task 2.
